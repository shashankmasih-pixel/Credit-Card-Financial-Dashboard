# Credit-Card-Financial-Dashboard
Interactive Credit Card Financial Dashboard built using PostgreSQL and Power BI to analyze customer spending behavior, transaction trends, revenue performance, and key financial KPIs through dynamic visualizations and data-driven insights.

# Project Objective
To develop a comprehensive credit card weekly dashboard that provides real-time insights into key performance metrics and trends, enabling stakeholders to monitor and analyze credit card operations effectively.
